# StopGame Парсер

## Цель проекта
Учебный проект для практики написания консольного приложения и парсинга HTML  

## Возможности
Что умеет программа:
* Обновлять список всех доступных фильтров для каталога игр
* Выводить справочник доступных фильтров
* Искать игры по нескольким фильтрам
* Распознавать опечатки во вводе пользователя и предлагать исправления
* Сохранять выгруженные данные в CSV

## Технологии
* `Python 3.14`
* `requests` — HTTP-запросы к сайту 
* `BeautifulSoup` — разбор HTML страниц каталога 
* `argparse` — подкоманды и параметры командной строки 
* `csv` — хранение справочников и результата 
* `logging` — диагностические сообщения с настраиваемым уровнем 
* `dataclasses` — классы для хранения данных 
* `difflib` — поиск похожих названий при опечатке 

## Установка
1. Клонировать репозиторий
2. Создать виртуальное окружение в папке с кодом: `python -m venv venv`
3. Установить зависимости: `pip install -r requirements.txt`
4. Обновить справочники: `python main.py update`

## Использование
`python main.py -h` - справка

`python main.py update` - обновить справочники доступных фильтров

`python main.py games --genres horror приключение` - выгрузить игры в перечисленных жанрах
